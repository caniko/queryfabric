# Governance

QueryFabric is governed as a neutral project with SynDB as the initial host and
reference integration, not the definition of the public scope.

Project expectations:

- keep the stable promise on the `queryfabric` facade crate
- preserve the separation between portable compiler behavior and host policy
- document compatibility changes in [`COMPATIBILITY.md`](COMPATIBILITY.md)
- document releases in [`CHANGELOG.md`](CHANGELOG.md) and [`RELEASE.md`](RELEASE.md)
- avoid introducing SynDB-specific public symbols into the neutral core
