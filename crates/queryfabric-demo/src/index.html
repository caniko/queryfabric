QueryFabric self-host demonstrator

A portable query API with data-sovereignty endpoints, running over a generic urban air-quality dataset (Postgres) and an S3-compatible object store.

  • GET /healthz — readiness
  • GET /catalog — queryable relations
  • GET /resources — station datasets and their access policy
  • POST /query — {"sql": "SELECT city, pm25 FROM readings JOIN stations ON readings.station_id = stations.station_id LIMIT 5"}
  • POST /resources/{id}/export — build the portable export bundle
  • GET /resources/{id}/bundle — read the sealed bundle back from the store
  • GET /resources/{id}/access-export — GDPR Art. 15 access export
  • POST /resources/{id}/erase — GDPR Art. 17 soft erasure (owner-only)
  • POST /resources/{id}/doi — mint a demonstration DOI
  • GET /federation/status — federation node identity
